# Структура Tatami iOS

## Назначение

Проектная граница будущего iPhone/iPad-клиента Tatami.

## Фактическое состояние

Целевой стек — Swift/SwiftUI. Граница и требования существуют, но готовый
production-клиент не следует считать реализованным без project files,
сборочных проверок и acceptance evidence.
