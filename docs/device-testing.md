# Проверка на iPhone с Windows

Цель: iPhone 14 Plus, iOS 18.6. Mac и платная Apple Developer Program
не требуются. Сборка из этого среза демонстрирует UI и локальную очередь:
микрофон и сервер заменены fakes.

1. Откройте приватный репозиторий клиента на GitHub → **Actions** → успешный
   запуск **iOS CI**. Внизу страницы, в **Artifacts**, скачайте
   **Tatami-unsigned**. Нужен вход в GitHub с доступом к репозиторию.
2. Распакуйте скачанный ZIP. Внутри находится `Tatami-unsigned.ipa`.
   Artifact хранится 14 дней; если он истёк, запустите новый workflow.
3. Установите Windows-версию с [официального сайта Sideloadly](https://sideloadly.io/).
   Подготовьте драйверы устройства через iTunes или Apple Devices. Если
   Sideloadly требует отдельные компоненты iTunes/iCloud, следуйте инструкции
   его текущей Windows-версии. Убедитесь, что iPhone виден на компьютере.
4. Подключите разблокированный iPhone USB-кабелем. Подтвердите **Доверять
   этому компьютеру** на iPhone и введите код устройства.
5. Запустите Sideloadly, выберите подключённый iPhone и перетащите
   `Tatami-unsigned.ipa` в окно программы. Выберите обычную установку с
   **Apple ID**, укажите свой бесплатный Apple ID и нажмите **Start**.
   Введите пароль и код двухфакторной аутентификации только в доверенном
   интерфейсе Sideloadly/Apple. Не помещайте их в репозиторий, Actions или чат.
   Подпись выполняется здесь, на компьютере, после CI.
6. На iPhone откройте **Settings → Privacy & Security → Developer Mode**
   (**Настройки → Конфиденциальность и безопасность → Режим разработчика**).
   Включите режим, перезагрузите телефон и подтвердите включение. Если пункт
   ещё не появился, повторно подключите телефон и выполните установку через
   Sideloadly, затем снова проверьте настройки.
7. Откройте **Settings → General → VPN & Device Management**
   (**Настройки → Основные → VPN и управление устройством**), выберите профиль
   разработчика своего Apple ID и нажмите **Trust / Доверять**.
   Если iOS предлагает дополнительную проверку/перезагрузку, выполните её.
8. Откройте **Tatami**. На вкладке **Запись** нажмите **Записать**, подождите,
   нажмите **Остановить**. Во вкладке **История** появится демонстрационный
   текст; проверьте **Копировать** и **Поделиться**. Перезапустите приложение
   и убедитесь, что история осталась. В **Настройки → Диагностика** должны быть
   только состояния, счётчики и категория ошибки.

Бесплатная подпись действует **7 дней**; затем повторно подпишите и установите
приложение через Sideloadly. У бесплатного аккаунта действует лимит **3 активных
sideload-приложений** на устройстве. Ограничения и варианты обновления сверяйте
с [FAQ Sideloadly](https://sideloadly.io/faq). Сохраняйте тот же Apple ID и
параметры bundle ID при повторной установке. Не удаляйте приложение для
обновления: удаление приложения удаляет его локальные данные.

При проблеме сначала проверьте результат CI, наличие драйверов, доверие к
компьютеру/профилю, Developer Mode и срок подписи. Успешная сборка CI ещё не
подтверждает установку на физический телефон: её проверяет владелец устройства.
