# Tatami iOS

Отдельный iPhone/iPad-клиент. Отвечает за native capture UX, offline queue,
history и вставку текста. Server, contracts и entitlements остаются общими.

## Рабочий протокол

Открытие, планирование, реализация, проверки и закрытие сессии выполняются по
[`WORKFLOW.md`](WORKFLOW.md). В начале прочитайте также `AGENTS.md`, `TASKS.md`
и `SESSION.md`.

Статус: проектная граница создана; реализация ещё не начата.
