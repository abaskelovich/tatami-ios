# Tatami iOS

Отдельный iPhone/iPad-клиент. Отвечает за native capture UX, offline queue,
history и вставку текста. Server, contracts и entitlements остаются общими.

## Рабочий протокол

Открытие, планирование, реализация, проверки и закрытие сессии выполняются по
[`WORKFLOW.md`](WORKFLOW.md). В начале прочитайте также `AGENTS.md`, `docs/BACKLOG.md`
и `STATUS.md`.

Статус: проектная граница создана; реализация ещё не начата.

## Краткий справочник команд

- **Проверить состояние** — провести read-only диагностику без открытия сессии.
- **Открыть сессию** — восстановить незакрытую работу и открыть/продолжить handoff.
- **Запросить план** или **Составить план** — получить план без автоматического начала реализации.
- **Начать работу** / **Вести работу** — реализовать согласованный scope, проверить,
  актуализировать документы и сделать корректные repository-scoped commits.
- **Сделать бэкап**, **Откатить**, **Задеплоить** — отдельные операционные команды
  с явным target и применимым runbook.
- **Подготовить релиз** проверяет готовность; **Выпустить релиз** изменяет
  distribution/production state и требует отдельного разрешения.
- **Поставить на паузу** сохраняет точный handoff; **Закрыть сессию** фиксирует
  проверенный результат, историю и следующий шаг.
